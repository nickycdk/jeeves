# Jeeves

A session-continuity plugin for Claude Code. The plugin, its README and its docs are in [`jeeves/`](jeeves/README.md); the planning documents and gate evidence are in [`docs/plans/`](docs/plans/).

Install: `/plugin install jeeves --marketplace <owner>/jeeves` (this repository is the marketplace). Contributing: [jeeves/CONTRIBUTING.md](jeeves/CONTRIBUTING.md). Licence: MIT.
