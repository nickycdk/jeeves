Tibbs 0.1.0 is the first public beta: a session-continuity plugin for Claude Code. It is not an Anthropic product.

## What it does

When the context of a long task reaches your threshold (50% by default), Tibbs waits for a safe stop, asks Claude for a handover, checks it against git and the commands it saw run, saves it, starts a fresh Claude Code conversation with `/clear` and continues your task from the validated handover, inside your normal terminal session. No API key, no server, everything stays on your machine.

- `/tibbs on [goal]` to start, `/tibbs status`, `pause`, `resume`, `rotate`, `off`, `history`, `purge`, `help`.
- Completion is accepted only when your Definition of Done checks ran and passed.
- If Claude Code refuses a plugin's `/clear`, Tibbs says so and runs in **assisted mode**: you type `/clear`, then `/tibbs continue`.
- Permission prompts and blockers still need you; Tibbs does not answer them.

## Supported

- Claude Code **2.1.319** and later (tested versions: `docs/compatibility.md`). Older versions are refused with a message.
- macOS (tested, including Cursor's terminal). Linux expected to work, not yet part of the release tests.
