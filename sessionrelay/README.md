# SessionRelay

A session-continuity plugin for Claude Code. When a managed task's context reaches a threshold, SessionRelay writes a verified handover, starts a fresh conversation in the same terminal and continues the task there.

**Status: pre-release, under development.** Nothing here is ready for use yet.

Available now: `/relay status` and `/relay help`. Automatic rotation is not built yet.

Supported: Claude Code 2.1.319 or later on macOS. Linux is expected to work but untested.
