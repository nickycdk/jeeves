Jeeves 0.3.7 is an update to the 0.3 public beta of the session-continuity plugin for Claude Code. It fixes two checks that sent good handovers back, and says why when a handover fails for good. It is not an Anthropic product.

## Fixed

- **Sub-bullets no longer count as untagged.** A tagged bullet with an indented list under it (`- [verified] New files:` then `  - api/a.php`) was sent back as "22 bullet(s) lack a tag". An untagged sub-bullet now belongs to the bullet above it, and its paths are checked with that bullet. A sub-bullet with its own tag is still its own bullet.
- **Naming another branch is no longer a wrong-branch claim.** "the PR branch `fix/x` was pushed" was read as a claim that `fix/x` is checked out. Only wording like "on branch x", "the current branch is x" or "branch `x` is the working branch" is checked now.

## Changed

- **The pop-up says why a handover failed.** When the handover fails its checks on every try, the pop-up names the last problem:

  ```text
  Handover failed its checks 3 times. Last problem: missing section "## Exact next actions". Nothing was cleared. /jeeves retry
  ```

  It used to say only "Handover was invalid after retries … Run /jeeves status", and `/jeeves status` cut the reason off.

The handover format (`v1`) and the state files are unchanged, so 0.3.6 and 0.3.7 read each other's tasks.

## Install

See the README's Install section. Verify the download: `shasum -a 256 -c jeeves-0.3.7.zip.sha256`.
