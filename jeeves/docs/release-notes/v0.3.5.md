Jeeves 0.3.5 is an update to the 0.3 public beta of the session-continuity plugin for Claude Code. It makes Jeeves useful in more projects. It is not an Anthropic product.

## Changed

- **Check suggestions for more projects.** When a task starts with no checks, `/jeeves on` now also suggests them for Python, Rust, Go and justfile projects, and uses your package manager:
  - `pnpm test`, `yarn test` or `bun run test` when the lockfile or the `packageManager` field names one (was always `npm`);
  - `uv run pytest`, `uv run ruff check .` and `uv run mypy` (or `poetry run …`) when `pyproject.toml` lists them as dependencies (not only as an optional extra, which `uv run` does not install) and `uv.lock` or `poetry.lock` exists. Without either lockfile, nothing is suggested for Python, because the bare tools usually live in a virtualenv that is not active;
  - `cargo test` and `cargo clippy` with a `Cargo.toml`; `go test ./...` and `go vet ./...` with a `go.mod`;
  - `just test` and `just lint` from a `justfile`.
  - A Makefile variable such as `test := ./...` is no longer read as a `test` target.

  Up to 4 suggestions, at most 2 from each source, with Makefile and justfile first, so a mixed repository gets a mix. As before, nothing is added or run until you type the command.
- **The README says exactly which repository files Jeeves reads**, and only to suggest checks: `package.json`, `Makefile`, the justfile and `pyproject.toml`, up to 256 KB each. For lockfiles, `Cargo.toml` and `go.mod` it only checks that they exist. Nothing from them is stored. The README said before that Jeeves does not read file contents, which was already not true of `package.json` and `Makefile`. PRIVACY.md says the same.
- **A shorter README.** Install, the quickstart and what you see come first. The turn-mode details, the auto-start rules and the full command table moved to `docs/turn-mode.md`, `docs/auto-start.md` and `docs/commands.md`.
- **`/jeeves help` lists the everyday commands first** (`on`, `off`, `status`, `pause`, `resume`, `rotate`, `check`, `done`), then the rest under `More:`.

The handover format (`v1`) and the state files are unchanged, so 0.3.4 and 0.3.5 read each other's tasks.

## Install

See the README's Install section. Verify the download: `shasum -a 256 -c jeeves-0.3.5.zip.sha256`.
