Jeeves 0.3.4 is a small update to the 0.3 public beta of the session-continuity plugin for Claude Code, made for the Claude plugin directory's review. Jeeves itself works as in 0.3.3. It is not an Anthropic product.

## Changed

- **Installs no longer download TypeScript.** `package-lock.json` is gone from the plugin folder: with it there, Claude Code ran `npm ci` when the plugin was installed and fetched TypeScript, a tool only developers need. Jeeves has no runtime dependencies and runs from its TypeScript source.
- **The README says what the mod does on your machine:** the programs it runs (read-only `git`, and a few file tools inside its own state folder), the files it writes (only its state folder), the one slash command it runs (`/clear`), the prompts it submits, what each hook changes, and that it uses no network.

The handover format (`v1`) and the state files are unchanged, so 0.3.3 and 0.3.4 read each other's tasks.

## Install

See the README's Install section. Verify the download: `shasum -a 256 -c jeeves-0.3.4.zip.sha256`.
