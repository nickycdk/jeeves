Jeeves 0.2.0 is the second public beta of the session-continuity plugin for Claude Code. It is not an Anthropic product.

## New

- **Window-aware default threshold.** A new task hands over at 40% on models with a context window above 200K tokens (for example 1M) and at 50% otherwise. `/jeeves status` shows the threshold in tokens too.
- **`/jeeves retry`** after a handover failed its checks, or after a possible rotation loop. A loop now stops for review (`NEEDS_REVIEW (POSSIBLE_LOOP)`) instead of failing for good. Retries are typed by you, never automatic, and count toward the limit of failed handovers in a row.
- **`/jeeves defaults`**: per-project threshold and checks for new tasks, kept in the state folder, never in your repository.
- **Check suggestions**: with no checks set, `/jeeves on` suggests up to 4 from `package.json` and `Makefile`. Nothing is added or run.
- **`/jeeves history --full`** and **`/jeeves stats`**: rotations, sessions, context at rotation, cost where known.
- Jeeves now **notices when another plugin skips its Stop hook** and turns itself off with a clear message, instead of looking on while never handing over.

## Known limits

- **Claude accounts in a Team organization are not supported for now.** On Claude Code 2.1.319, such accounts get a built-in security plugin (`cc-plugin-sec-default`) that runs before every installed plugin and skips the Stop, SessionStart, compaction and system-prompt hooks Jeeves relies on. Jeeves cannot hand over there. It notices after the first answer: the status line shows `off: Stop hook skipped` and `/jeeves on` is refused. See the troubleshooting guide.
- Claude Code **2.1.319** and later only. The test kit also passes on 2.1.302 to 2.1.316 (`docs/compatibility.md`), but no live rotation ran on those versions, so they stay unsupported.
- macOS (tested, including Cursor's terminal). Linux is expected to work but is not part of the release tests. VS Code's terminal was not tested.
- Permission prompts and blockers still need you; Jeeves never answers them.
