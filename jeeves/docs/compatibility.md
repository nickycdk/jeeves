# Compatibility

Generated by `node scripts/compat.mjs` on 2026-11-08 for Jeeves 0.2.0 on Darwin 27.2.0.
Each version was installed from npm into a scratch folder and ran `claude plugin validate . --strict` and `claude plugin test .` (the engine's test kit: no model calls, logged out).

**Supported:** Claude Code 2.1.319 or later (`MIN_VERSION` in `src/core/probe.ts`); older versions run Jeeves as unsupported (it stays off and says which version it needs). A passing row below for an older version means only that the mod loads and its tests pass in that version's test kit; rotation in a live session was verified on 2.1.319 only. On Claude accounts in a Team organization Jeeves runs in turn mode (README, Requirements); the mod tests run in that mode too (`npm run test:mod:turn`).
